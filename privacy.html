This policy covers the website at this address and "Honestly Happened Poster" (the "Tool"), a private tool the owner of the Honestly Happened channel uses to publish videos to the channel's own accounts and read their statistics.

Who uses the Tool

Only the channel owner. The Tool is not offered to anyone else, and nobody else can sign in to it.

What data the Tool accesses

With the channel owner's permission, given through each platform's own sign-in screen, the Tool accesses only the channel's own accounts:

  • YouTube (through YouTube API Services): uploading and scheduling videos, the channel's name, and the channel's video statistics (views, likes, comments, watch time, average view percentage, shares, subscribers gained).
  • Facebook and Instagram (Meta Graph API): publishing Reels to the channel's own Page and Instagram account, and reading their statistics.
  • TikTok (TikTok Content Posting API): publishing videos to the channel's own account, and reading their statistics.

The Tool does not access viewers' personal data, does not read comments' authors, and does not collect any information from people who watch the videos or visit this website.

How the data is used and stored

Statistics are used only to understand which videos perform well and to improve future videos. Access tokens and statistics are stored only on the channel owner's own computer. They are not sold, shared with or transferred to anyone, and are not used for advertising.

Retention and deletion

Statistics are kept for as long as they are useful for the channel's own analysis and can be deleted at any time by the owner. Access can be revoked at any time, which stops the Tool immediately:

  • Google / YouTube: security.google.com/settings/security/permissions
  • Facebook and Instagram: Facebook Settings → Business integrations
  • TikTok: Settings and privacy → Security → Manage app permissions

YouTube API Services

The Tool uses YouTube API Services. Use of YouTube data through the Tool is also covered by the YouTube Terms of Service and the Google Privacy Policy.

This website

This website has no accounts, forms, analytics or tracking cookies. It is hosted on GitHub Pages, which may keep standard server logs (see GitHub's privacy statement). The fonts are loaded from Google Fonts.

Changes and contact

Changes to this policy will be posted on this page with a new date. Questions: use the contact email on our YouTube channel's About page.
